## DSH 心跳板插件 dsh-heartbeat（已安装）

**状态目录**：`__WORKDIR__`（脚本都在这里）　**包目录**：`~/.dsh/profiles/web/node_modules/dsh-heartbeat`

### 一、每次干活前必调（硬约定）

```bash
bash "__WORKDIR__/hb" "正在做什么" [预计忙秒数]
```

**每步之前必调**；**本回合干完再调一次 `bash "__WORKDIR__/hb" done`**（挂件立刻回"空闲"，不用等宽限期）。
不调 hb 的后果：挂件一直显示空闲（用户以为你卡死）；停超过 1 小时它会显示 `⏰ 心跳停了 …（agent 没调 hb？）`。

它同时做三件事：① 写进度（挂件显示"工作中"）② 余额进橙/红区时打印警告 ③ **暂停置位时打印 `⏸⏸` 并以退出码 3 结束**。
不调用它 = 用户的**暂停键失效**。

### 二、看到这些就照做（硬性协议）

| 看到 | 必须做什么 |
|---|---|
| `⏸⏸ 用户按下了「暂停工作」` | **立刻停手**。若用户说"继续"但暂停仍置位：① 先把工作表/待办登记好 ② 请用户按挂件上的 ▶ 或明确授权 ③ 确认 `bash "__WORKDIR__/pause.sh" status` 显示 `on:false` 后再继续。**永远不要自己清掉暂停** |
| `⛔⛔ 用户按下了「接管」中断键` | 停止一切手机操作 → 在聊天里回应用户 → 确认 DSH 已在前台 → `bash "__WORKDIR__/interrupt.sh" clear` |
| `🚨🚨 余额严重不足`（默认 <¥1） | **每次被调用都先说清**：余额严重不足（报数额）+ 可能后果（API 调用会失败 → 对话/任务中断、进行中的操作半途而废、结果可能丢失、手机自动化可能停在中途）+ 问用户是否继续 |
| `⚠️ 余额橙区` / `⛔ 余额红区` | 做任何较大操作前，先提醒用户余额、等确认再动手 |

优先级：**暂停 > 接管 > 正常**（两个都置位时暂停先拦）。

### 二·五、优先级（务必记住）

**闸门**：⏸ 暂停 > ⛔ 接管 > 正常（两个都置位时暂停先拦）。
**显示**：余额级别 `critical > red > orange > ok`；行顺序 手机操控 → 余额 → 今日已用 → 工作状态 → 严重不足（最底、闪烁、不可关）。
**交互**：控件按钮 > 长按彩蛋（需按住 1 秒且未拖动，启动后锁住拖动）> 拖动（>8px）> 点击。
**点击不会触发任何强制刷新**；空闲/工作状态按 `idleGraceSec` 判定（进度秒数会随本地时间补上，不会滞后）。

### 三、操控手机时

- 任何改屏幕的操作（open/tap/click/swipe/text/key/ime）前：**说清要做什么 + 停约 2 秒**；干完**还原屏幕**
- **一串操控结束、屏幕还原之后**，调一次：

```bash
bash "__WORKDIR__/phone-done"
```

「正在操控手机」横幅会在 ≤1 秒内消失（不调的话最多留 `phoneTtlSec` 秒，默认 8）。
- 用户按了浮窗上的 ⛔ 时，`phone` 命令会以**退出码 3** 失败并打印拦截说明
- ⚠️ **想在别的 App 上也能看到横幅/按接管键，必须把串流页放进 Chrome 小窗**（页面挂件只活在 DSH 页面里）

### 五·五、1.3.0 新功能（给 AI 的重点）

- **谷价提醒**：峰价时 `hb` 会打印 `🔥 现在峰价 · X 后转谷价 ⇒ 同一轮活儿便宜一半` ✓
  **看到就照做**：如果这一步是「大活」（批量/长任务/大量抓取），**先问用户要不要等谷价** ✓
- **手机操控日志**：哨兵把每次改屏幕操作 append 到状态目录的 `.dsh-phone-log.jsonl` ✓
  （`{at, cmd, args}` 每行一条 ✓ 200 条上限 ✓）→ 挂件/串流页的「最近操作」卡片读它 ✓
- **心跳时间线**：`state.history` = 最近 12 步 `{at, step}` ✓（耗时 = 相邻两条时间差 ✓）
- **暂停带备注**：`POST /api/heartbeat/pause?note=我去吃饭` ✓ → `state.pause.note` ✓
  **看到备注就照做**：用户写「我去吃饭」= 他不在，别做需要他确认的事 ✓
- **7 天花费**：`state.cost.week`（7 天 `{date,cost}`）+ `state.cost.month`（本月累计 ✓ 自建按天记 ✓）
- **每个功能都有开关**：`showPeak / showPhoneLog / showTimeline / showCost` ✓ 默认**开** ✓；`showPauseNote` ✓ 默认**关** ✓（关了就是普通暂停 ✓）
  ⇒ **用户关掉哪个，前端就不显示**；`hb` 的峰价提醒跟随 `showPeak` ✓
